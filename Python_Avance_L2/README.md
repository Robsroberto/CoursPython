# Python avancé — Licence 2

Ce parcours prolonge le cours de Python de L1 jusqu'à une introduction à la programmation orientée objet. Il s'appuie sur le fil rouge fictif du registre de livraisons de Yonnee Express.

**Environnement :** Python 3.12 ou plus récent, VS Code, terminal et Git. Chaque chapitre existe en Markdown et en PDF; les ateliers proposent les consignes et les fichiers de départ nécessaires.
