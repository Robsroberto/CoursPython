# Python pour la science des données — Licence 2

Ce parcours indépendant du cours Python avancé étudie l'analyse de données avec Python à partir des prix des denrées sur les marchés du Sénégal. Il s'adresse aux étudiants ayant suivi le Python de L1.

**Environnement :** Google Colab (sans installation) ou JupyterLab avec Python 3.12. Les supports de cours et ateliers sont proposés en Markdown et en PDF.
